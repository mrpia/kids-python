Zeilen mit #

Notizen für Menschen. Python überspringt sie. Dort steht deine Aufgabe.

Stoppen: ins Terminal klicken, dann Ctrl + C.

01

Text anzeigen

Scratchsage Hallo!
print("Hallo Welt!")→Hallo Welt! print("\\o/")→\o/

Text steht immer zwischen "Anführungszeichen". Jedes print macht eine neue Zeile. Für ein \ im Text schreibst du zwei: \\

02

Rechnen

Scratch( ) + ( )
+plus
-minus
*mal
/geteilt
print(3 + 4)→7 print("3 + 4")→3 + 4 print(10 / 2)→5.0

Zum Rechnen keine Anführungszeichen. Mit / zeigt Python immer eine Kommazahl, mit Punkt statt Komma.

03

Variablen

Scratchsetze alter auf 11

Eine Variable ist eine Box mit Namen. Der Name hat keine Leerzeichen: lieblingszahl

name = "Lena"Text: mit "" alter = 11Zahl: ohne "" print(name, "ist", alter)→Lena ist 11

Das Komma zeigt mehrere Dinge nacheinander, mit Abstand.

04

Fragen stellen

Scratchfrage … und warte 
name = input("Wie heisst du? ")
print("Grüezi", name + "!")Im Terminal (unterstrichen = das tippst du):Wie heisst du? Lena
Grüezi Lena!

Das Programm wartet, bis du tippst und Enter drückst. Mit + klebt Python Text ohne Abstand zusammen.

Achtung: input() gibt immer Text. Zum Rechnen machst du mit int() eine Zahl daraus:
alter = int(input("Wie alt bist du? "))

05

Entscheiden

Scratchfalls … dann … sonst 
antwort = input("Was ist 7 + 5? ")
if antwort == "12":       ← Doppelpunkt!
    print("Richtig!")      ← eingerückt
else:
    print("Leider falsch.")

Einrücken = 4 Leerzeichen oder Tab-Taste. Das ist wie das Innere eines Scratch-Blocks. if geht auch ohne else.

==ist gleich
!=ist nicht gleich
>grösser als
<kleiner als

Ein = oder zwei? alter = 11 speichert. alter == 11 fragt: Ist das gleich?

Die Antwort von input() ist Text, also vergleichst du mit "12". Mit int() wird sie eine Zahl, dann ohne Anführungszeichen: if alter > 12:

06

Punkte zählen

Scratchändere punkte um 1 
punkte = 0                am Anfang
punkte = punkte + 1       bei «Richtig!»
if antwort.lower() == "bern":

.lower() macht alle Buchstaben klein. So sind Bern, BERN und bern alle richtig. Schreibe die richtige Antwort im Code deshalb klein!

07

Zahlenraten

Scratchwiederhole bis … 
import random                    ganz oben
geheim = random.randint(1, 100)  1 bis 100
tipp = 0
while tipp != geheim:
    tipp = int(input("Dein Tipp: "))

Andersrum! Scratch wiederholt, bis es stimmt. Python wiederholt, solange es nicht stimmt. Darum steht hier !=.

Fehler sind normal! Auch Profis machen sie jeden Tag. Hilfe gibt es auf der Rückseite. Python 3.13 · VS Code

Wenn etwas nicht klappt

Fehler sind normal.
Auch Profis korrigieren einen nach dem anderen.

So liest du eine Fehlermeldung

  File "...\08_fehlersuche.py", line 311
    print("Hallo, ich bin Robo, der Roboter!)
          ^2
SyntaxError: unterminated string literal3
  1. 1line 31 heisst Zeile 31. Dort oder kurz davor steckt der Fehler.
  2. 2Das Dach ^ zeigt ungefähr auf die Stelle.
  3. 3Die letzte Zeile sagt, was falsch ist. Die Tabelle unten übersetzt sie.
  4. 4Python zeigt immer nur einen Fehler. Korrigiere ihn und starte nochmals.

Hilfe!

Es passiert nichts?
Das Programm wartet auf deine Antwort. Klicke ins Terminal unten, tippe und drücke Enter.
Es hört nicht mehr auf?
Klicke ins Terminal und drücke Ctrl + C.
VS Code fragt nach einem Debugger?
Du hast F5 gedrückt. Drücke Esc und starte mit dem Knopf ▶.
Rot unterstrichen?
VS Code hat schon vor dem Start einen Fehler gefunden. Schau dir diese Stelle genau an.
Richtig geantwortet, aber das Programm sagt «falsch»?
Hier zeigt Python keinen Fehler. Steht die richtige Antwort im Code klein, also "bern"? Vergleichst du mit "12" statt mit 12?
